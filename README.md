# 🍽️ 식당 예약 시스템 (Dine Reserve)

회원과 비회원 모두 예약할 수 있는 식당 예약 시스템입니다.
Redis 기반 분산 락으로 동시성을 제어하고, 스케줄러로 예약 알림과 노쇼 처리를 자동화합니다.

---

## 📌 프로젝트 소개

- **수용량 관리 방식**: 시간대(타임슬롯)별 정원 방식
- **비회원 본인 확인**: 예약 시 설정한 비밀번호(`전화번호 + 비밀번호`)로 검증
- **목표**: 동시성 제어 · 중복 예약 방지 · 예약 알림 등 실무형 기능을 학습/구현

---

## 👥 사용자 구분

| 구분 | 인증 방식 | 식별 / 검증 |
| --- | --- | --- |
| **회원** | 로그인 (JWT) | `memberID` |
| **비회원** | 없음 | `전화번호 + 예약 비밀번호` |
| **관리자** | 로그인 (ADMIN) | 권한 기반 |

---

## ✨ 주요 기능

### 핵심 기능

### 1. 예약 가능 시간 조회

- 영업시간 · 휴무일 · 브레이크타임 기준으로 타임슬롯 생성 (예: 1시간 단위)
- 슬롯별 잔여 정원 계산 후 응답
- 정원이 0인 슬롯은 마감 처리

### 2. 예약 생성

- **회원**: `memberUUID`로 식별, 인원 수 입력
- **비회원**: 이름 + 전화번호 + 4자리 비밀번호 + 인원 수 입력
- **공통**: 선택 슬롯의 잔여 정원 확인 → 차감 → 예약 저장 (동시성 처리 핵심 구간)

### 3. 예약 취소

- 취소 마감 시간(예: 방문 2시간 전) 이내만 허용
- 회원은 로그인 기반, 비회원은 `전화번호 + 비밀번호` 검증 후 허용
- 취소 시 해당 슬롯 정원 즉시 복구

### 4. 관리자 일정 관리

- 영업시간 / 휴무일 / 브레이크타임 설정
- 예약 정책 설정: 최소·최대 인원, 예약 가능 기간(오늘부터 N일), 취소 마감 시간, 슬롯당 정원
- 예약 목록 조회 / 상태 변경 / 강제 취소

### 심화 기능

### 동시성 제어 + 중복 방지

- Redis 분산 락(`lock:reservation:{storeUUID}:{date}:{slot}`)으로 슬롯 단위 직렬화
- 락 구간 안에서 `잔여 정원 확인 → 차감 → 예약 저장`을 원자적으로 처리해 오버부킹 방지
- 동일인 중복 예약 차단: 회원 = `memberUUID`, 비회원 = `전화번호` 기준

### 추가

- **노쇼 자동 처리**: 방문 시간이 지났을때 고객이 오지 않으면 자동으로 예약을 `NO_SHOW`로 전환 가능

## 🛠️ 기술 스택

| 기술 | 역할 |
| --- | --- |
| **Spring Boot** | REST API, 비즈니스 로직 |
| **Spring Security + JWT** | 회원 / 관리자 인증·인가 |
| **JPA (Hibernate)** | 엔티티 영속화, 동일인 중복 예약 방지 유니크 제약 |
| **Redis (Redisson)** | 슬롯 단위 분산 락, 동시성 제어 |
